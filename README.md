# Shelf

Платформа для отслеживания фильмов, книг и игр в одном месте

> **Проект на ранней стадии разработки** Код открыт с самого начала, структура проекта и эндпоинты могут ломаться и переделываться. Финальная версия и стабильная работа не гарантируются из-за малого опыта в разработке и возможных сложностей.

## Стек

- **Язык и фреймворк:** Python, FastAPI
- **База данных и ORM:** PostgreSQL, SQLAlchemy, Alembic
- **Тестирование:** Pytest

## Масштаб

Текущий репозиторий содержит только бэкенд. Фронтенда в ближайших планах не планируется до тех пор пока не получится работающий бэкенд. На сегодняшний день я сосредоточен на работе с API, бизнес-логике и хранении данных.

## Зачем нужно

## Установка и запуск

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/YanarD78/shelf.git
    cd shelf
    ```

2. **Создайте и активируйте виртуальное окружение**

    ```bash
    python -m venv venv # Создание виртуального окружения
    source venv/bin/activate # Windows: venv/Scripts/activate
    ```

3. **Установите зависимости**

    ```bash
    pip install -r requirements.txt
    ```

4. **Создайте файл `.env`**

    *Пример переменных окружения описан в .env.example*

5. **Запустите программу:**

    ```bash
    uvicorn app.main:app --reload
    ```
