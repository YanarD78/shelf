# Shelf

Платформа для отслеживания фильмов, книг и игр в одном месте

> **Проект на ранней стадии разработки** Код открыт с самого начала, структура проекта и эндпоинты могут ломаться и переделываться. Финальная версия и стабильная работа не гарантируются из-за малого опыта в разработке и возможных сложностей. Пока что не юзабельно.

## Стек

- **Python** + **FastAPI**
- **PostgreSQL**
- **SQLAlchemy**

## Масштаб

Текущий репозиторий содержит только бэкенд. Фронтенда в ближайших планах не планируется до тех пор пока не получится работающий бэкенд. На сегодняшний день я сосредоточен на работе с API, бизнес-логике и хранении данных.

## Зачем нужно

Проект был создан в целях практики и является моим первым "масштабным" приложением. В первую очередь разработка ведётся для себя, так как сервисы вроде **Letterboxd** не отвечают моим нуждам

## Установка

```bash
git clone https://github.com/YanarD78/shelf.git
cd shelf
```

```bash
python -m venv .venv # Создание виртуального окружение
source .venv/bin/activate
```

```bash
pip install -r requirements.txt # Установка из зависимостей
```

Пример переменных окружения описан в .env.example
